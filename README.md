# Field Ops Guide: PC Assembly Standard

A comprehensive, multi-language guide (English, Spanish, German) designed to standardize the PC assembly, cabling, and deployment process.

## 🚀 Features

*   **Multi-language Support:** Seamless switching between EN, ES, and DE.
*   **Interactive Checklists:** Track progress across different modules (Hardware, Cabling, OS).
*   **Local Storage Persistence:** Progress is saved automatically in the browser.
*   **Responsive Design:** Optimized for tablet and mobile field usage.
*   **Visual Documentation:** Clear diagrams for headers, front panel connectors, and cabling standards.

## 🛠️ Tech Stack

*   **Framework:** Astro
*   **Styling:** Tailwind CSS
*   **Interactivity:** React
*   **State Management:** Nano Stores / LocalStorage

## 📦 Installation & Setup

1.  Clone the repository:
    ```bash
    git clone https://github.com/YOUR_USERNAME/pc-assembly-standard.git
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run development server:
    ```bash
    npm run dev
    ```

## 📖 Modules

1.  **Prep & Safety:** ESD safety and workspace setup.
2.  **Hardware Assembly:** CPU, RAM, NVMe, and Motherboard installation.
3.  **Cabling Standard:** Professional cable management and routing.
4.  **First Boot:** BIOS configuration and initial verification.
5.  **OS & Drivers:** Windows deployment and driver installation.
